# Community conduct

Luna welcomes questions, bug reports, documentation improvements, and code contributions.

Treat other contributors with respect. Critique ideas and implementation choices without attacking people. Harassment, threats, discriminatory remarks, and publishing someone else's private information are unacceptable.

Use synthetic examples in public issues. Keep credentials, personal conversations, addresses, financial records, and installation logs containing private details out of the repository.

Maintainers may edit or remove content, close discussions, or restrict participation to protect contributors and keep the project useful. Explain moderation decisions when doing so can preserve people's privacy.

Report conduct concerns privately through the maintainer's GitHub profile. Do not post sensitive evidence in a public issue.
