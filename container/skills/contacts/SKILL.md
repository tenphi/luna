# Mac Contacts

Use contact tools (`search_contacts`, `get_contact`, `list_contacts`, `create_contact`, …) for **Apple Contacts**. Never run `osascript` in Bash.

## Tips

- Prefer `search_contacts` before create to avoid duplicates.
- Confirm before `delete_contact` / `delete_contact_group`.
- Use groups via `list_contact_groups` / `add_contact_to_group` when organizing.
